01 / Robotics · GC Valobot

A quadruped built to explore.

Designing a four-legged robot to follow a line and navigate a maze: a project combining mechanics, perception and embedded control. Parallelogram leg mechanisms keep the feet perpendicular to the base, while the kinematic model enables translation and rotation commands.

CATIA V5Raspberry Pi PicoKinematicsI2C
4articulated legs
8servomotors
550 gtotal mass
Behind the project
  • Mechanical design and motion analysis using CATIA V5 and GeoGebra.
  • Line detection with an OV7670 camera at 160 × 120 pixels and 3 frames per second.
  • Three VL53L0X sensors to detect the maze walls.
  • Tasks distributed across the Pico’s two cores, with synchronized I2C communication.
  • Servo control through a PCA9685, with closed-loop correction planned to refine motion.
02 / Perception · EPFL Racing Team

Reading the track with LiDAR.

With EPFL Racing Team, I worked on perception and integration of an Ouster OS1 rev 7 LiDAR for Formula Student Driverless events. The ROS pipeline covers point cloud acquisition and processing, ground removal and DBSCAN clustering to identify cones. The work also includes integrating the LiDAR’s IMU and creating an interface to test its measurements.

03 / Control systems

PID table

Designing an educational kit for a ROBOVALY workshop at EPFL: a single-axis table automatically returns a ball to a reference position. The project combines 3D modelling and printing, PCB design, ToF distance sensor integration, PID tuning and a graphical user interface.

PID controlToF sensorsElectronics
04 / Control systems · Parallel manipulator

2D PID table · 3-RRS platform

Balancing a ball on a 3-RRS parallel platform using two-dimensional PID control. A four-wire resistive touchscreen measures the ball’s X and Y position. The controller calculates pitch and roll corrections, then inverse kinematics converts this orientation into angles for the three servo-driven joints.
